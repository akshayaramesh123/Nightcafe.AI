# 🎨 Text-to-Image Generation using NightCafe AI

## 📌 Project Overview

This project demonstrates how AI can generate high-quality images from text prompts using **NightCafe AI**. By providing descriptive prompts, the AI creates unique and realistic digital artwork.

## 🚀 Features

* Generate images from natural language prompts.
* Create realistic and artistic AI-generated images.
* Explore different art styles and creative concepts.
* Easy-to-use AI image generation platform.

## 🛠️ Tool Used

* **NightCafe AI**
* AI Image Generation
* Prompt Engineering
* GitHub
